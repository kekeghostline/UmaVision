# UmaVision

スマホ向けブラウザアプリ。競馬の予想をAIに行わせ、ユーザーの資金額に応じたおすすめの馬券を表示する。

## 主な機能

- 指定した日付と競馬場とレース番号に対応する出馬表をJRAのサイトから取得し表示
- 資金額を入力し、3種類のスタイル（堅め、バランス、攻め）を選択し、AIによる予想結果を表示
- AIの予想結果履歴を保存でき、いつでも表示、削除ができる
- 予想結果履歴は、レースが未発走なら、再予想（最新情報を再取得してAI予想）が可能

## 技術スタック

- フロントエンド: Next.js (TypeScript)
- ホスティング: Vercel
- AI予想: Claude API
- 認証・データ保存（予想結果履歴）: Supabase (Postgres + Auth)
- 出馬表スクレイピング: JRAサイトの内容次第でPlaywright等のヘッドレスブラウザが必要になる可能性があり、その場合はVercelのサーバーレス関数の実行時間・メモリ制約を避けるため、スクレイピング処理をCloud Run等の別サーバーに切り出すことを検討
